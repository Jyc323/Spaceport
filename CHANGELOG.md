# Changelog

## 0.1.0 — first public preview

- Save the windows of the current desktop as a named template: apps, positions, browser tabs (Edge / Chrome / Brave / Chromium) and Terminal working folders
- Apply a template to any desktop from the menu bar; apps that aren't running are launched
- Automatically apply a chosen template when you switch to a newly created desktop (built-in "Edge + Terminal")
- Multi-monitor aware: saves and applies per display
- Name your desktops; the name of the current desktop is shown in the menu bar
- Templates stored as editable JSON in `~/Library/Application Support/Spaceport/templates.json`
- English and Chinese interface
